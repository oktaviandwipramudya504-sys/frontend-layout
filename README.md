# Resonance - Admin Dashboard Layout

This repository contains the core layout master (*base template*) for the **Resonance** Administrator dashboard. Built with a sleek, dark-themed luxury aesthetic designed to provide a premium user experience for backend management.

## Key Features
* **Premium Dark Theme:** High-contrast black and gold branding layout (`#dab01b`).
* **Jinja2 Templating Ready:** Uses flexible blocks (`{% block konten %}`) for seamless integration with Python Flask.
* **Fully Responsive:** Styled using Bootstrap with sticky-top navigation and blur background-filter effects.
* **Pre-configured Plugins:** Equipped with Font Awesome v6, jQuery 3.7.1, and SweetAlert2.
